# Grill a scoped decision

Read and follow [the interview method](references/interview.md). When terminology or ownership is unclear, also read [domain clarification](references/domain.md).

Work within the user's current issue or milestone. Preserve an approved plan and clarify only consequential gaps or contradictions. End with a concise summary of settled decisions, assumptions, observable acceptance criteria, non-goals, and deferred or unresolved questions. State whether the task is ready for implementation and what prevents readiness.

This standalone entry point authorizes discussion and permitted read-only investigation, not code changes, tracked documentation edits, delegation, or external writes. Give the summary in conversation; do not create run records solely for this interview. A separately invoked workflow can reuse the interview reference within its existing authority.
